# 💌 Інтерактивне Запрошення на Побачення

Повний готовий проект запрошення з підтримкою анімацій поцілунків, адаптацією під мобільні телефони та email-сповіщеннями.

---

## 🛠️ Файлова структура проекту:
- `index.html` — основна сторінка запрошення
- `style.css` — красиві мобільні стилі та анімації
- `script.js` — сенсорні події, анімації та відправка сповіщень
- `server.js` — Node.js сервер сайту та API сповіщень
- `.env` — локальні налаштування Telegram/email
- `package.json` — конфігурація Node.js

---

## 🚀 Як відкрити на телефоні

Для доступу з телефону запустіть сервер командою `node server.js`. У терміналі з'явиться адреса комп'ютера в локальній мережі. Відкрийте її на телефоні, підключеному до тієї ж Wi-Fi мережі; за потреби дозвольте Node.js доступ через брандмауер Windows. Не закривайте термінал, поки користуєтеся сайтом.

### Публікація на Render

1. Завантажте весь проєкт у приватний GitHub-репозиторій. Не додавайте `.env` до Git.
2. У Render виберіть створення Blueprint і під'єднайте цей репозиторій. Файл `render.yaml` налаштує сервіс.
3. У Render задайте потрібні секретні змінні середовища та завершіть створення сервісу.
4. Надішліть отримане HTTPS-посилання. Воно відкривається з різних мереж, поки Render-сервіс доступний.

Безкоштовний план може присипляти сервіс після неактивності, тому перше відкриття іноді займає довше. Для постійно активного сервісу потрібен платний план. Для email-сповіщень потрібен запущений Node.js-сервер.

Відкрийте адресу сайту через HTTPS на телефоні. Після першого завантаження інтерфейс кешується для офлайн-використання; надсилання email потребує інтернету. У меню браузера виберіть «Додати на головний екран», щоб запускати сайт як застосунок.

Для Telegram-бота створіть бота через @BotFather, скопіюйте його токен і ID чату, а потім задайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Для email можна залишити `RESEND_API_KEY`, `EMAIL_TO` і `EMAIL_FROM`. У Render внесіть ці значення в Environment; локально їх можна зберігати в `.env`. Секрети не додавайте до Git.

Сервер працює на вбудованих модулях Node.js, додаткове встановлення пакетів не потрібне. На LAN-адресі інтерфейс працює з телефону; встановлення як офлайн-застосунку потребує HTTPS.
